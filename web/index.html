How it works

Finds where it starts

It walks the call graph down from the alert to the deepest unhealthy service, and rules out every change that is not on that path.

Fixes it safely

It rolls back, restarts or turns off a flag, as a dry run first. A hook blocks any real action that was not dry-run, then the fix is verified.

Remembers

The incident goes back into the graph with its root cause and fix, so the next agent starts from what the last one learned.

What the graph changes

The same agent on six injected failures, 48 runs. Without the graph it gets only service health, logs and a list of recent changes.

Get started

  1. Install 
    curl -fsSL https://rootpath.iwhitebird.com/install.sh | sh
  2. Connect

    It asks where your FalkorDB is, local Docker or FalkorDB Cloud, and sets up Claude Code, Codex and Cursor.

    rootpath init
  3. Use it

    In Claude Code, inside your repository: map your system into the graph, then hand it an incident.

    /rootpath:map
/rootpath:oncall checkout is throwing 500s

Rootpath runs on your machine against your own FalkorDB. A hosted Rootpath Cloud is coming soon.
